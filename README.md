# FarmGuys Website

A static, single-page site for FarmGuys, which connects local farms with health-conscious consumers through targeted social media, digital marketing, and streamlined online ordering.

## Files
- `index.html`: page content and structure
- `styles.css`: styling and responsive layout
- `script.js`: mobile menu, scroll effects, contact form handling

## Preview
Open `index.html` in a browser. No build step is needed.

## Contact form
Messages go to farmguysmarketing@gmail.com through FormSubmit (formsubmit.co). The first message sent triggers a one-time activation email to that inbox; click the link in it to start receiving messages. The address is set as `CONTACT_EMAIL` in `script.js`.

## Deploy
Live at https://farmguysmarketing.com, served by GitHub Pages from this branch. The `CNAME` file sets the custom domain; DNS for the domain is managed at GoDaddy (4 A records to GitHub Pages, `www` CNAME to `longballdriver.github.io`).
