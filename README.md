# FarmGuys Website

A static, single-page site for FarmGuys, which connects local farms with health-conscious consumers through targeted social media, digital marketing, and streamlined online ordering.

## Files
- `index.html`: page content and structure
- `styles.css`: styling and responsive layout
- `script.js`: mobile menu, scroll effects, contact form handling

## Preview
Open `index.html` in a browser. No build step is needed.

## Contact form
The form validates input but doesn't send anything yet. To receive submissions, set `FORM_ENDPOINT` in `script.js` to a form service URL (Formspree, Netlify Forms, Basin, etc.).

## Deploy
Works on any static host: GitHub Pages, Netlify, Vercel, or Cloudflare Pages.
